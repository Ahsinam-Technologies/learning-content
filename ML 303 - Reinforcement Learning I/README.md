# ML 303 — Reinforcement Learning I

**Academic Classification:** Core ML  
**Phase in Master Curriculum:** Φ 07  
**Academic Prerequisites:** MATH 105, ML 102

## Course Overview
Markov Decision Processes (MDPs), Bellman equations, dynamic programming, Monte Carlo methods, Temporal Difference learning (Q-Learning, SARSA), function approximation, and Policy Gradients. Prerequisite for RLHF.

- First-Principles Theoretical & Mathematical Derivations

- Problem Sets, Implementations & Benchmark Labs
- Direct Theoretical & Applied Support for Downstream Computing, AI & Systems
