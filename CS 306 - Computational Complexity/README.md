# CS 306 — Computational Complexity

**Academic Classification:** Core Theory  
**Phase in Master Curriculum:** Φ 05  
**Academic Prerequisites:** CS 206  

---

## Course Overview
Complexity classes (P, NP, co-NP, BPP, PSPACE, EXPTIME), polynomial-time reductions, Cook-Levin theorem, interactive proofs, and hardness of approximation.

---

## Key Curriculum Pillars
- First-Principles Theoretical & Mathematical Derivations
- Algorithmic Design, Systems Architecture & Proofs
- Problem Sets, Implementations & Benchmark Labs
- Direct Theoretical & Applied Support for Downstream Computing, AI & Systems
