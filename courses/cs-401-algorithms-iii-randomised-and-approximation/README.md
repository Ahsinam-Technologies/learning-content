**Academic Classification:** Prerequisite for High-Scale Data Science

## Course Overview
Randomized algorithms, Chernoff bounds, Monte Carlo and Las Vegas methods, hashing algorithms (Count-Min sketch, HyperLogLog, Locality Sensitive Hashing - LSH), and approximation bounds.
