# MATH 306 — Measure Theory

**Academic Classification:** Prerequisite for Modern Probability Theory  
**Phase in Master Curriculum:** Φ 05  
**Academic Prerequisites:** MATH 301, MATH 305  

---

## Course Overview
Sigma-algebras, Borel measures, Lebesgue measure, measurable functions, Lebesgue integration, monotone and dominated convergence theorems, Radon-Nikodym derivatives, and Fubini theorem.
