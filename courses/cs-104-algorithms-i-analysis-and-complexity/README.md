# CS 104 — Algorithms I: Analysis & Complexity

**Academic Classification:** Prerequisite  
**Phase in Master Curriculum:** Φ 03  
**Academic Prerequisites:** CS 103, MATH 104

## Course Overview
Asymptotic notation (Big-O, Omega, Theta), divide-and-conquer, greedy algorithms, dynamic programming, graph traversal (BFS/DFS, Dijkstra), and complexity bounds.

- First-Principles Theoretical & Mathematical Foundations

- Integration with Downstream Machine Learning, Data Science & Cloud Systems
