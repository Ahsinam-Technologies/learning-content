# ML 302 — Computer Vision II

**Academic Classification:** Prerequisite for Multimodal Vision-Language Models  
**Phase in Master Curriculum:** Φ 07  
**Academic Prerequisites:** ML 206, ML 202

## Course Overview
Deep convolutional networks (ResNet, ConvNeXt), object detection architectures (YOLO, Faster R-CNN), semantic/instance segmentation (U-Net, Mask R-CNN), and visual attention.

---

## Key Curriculum Pillars
- First-Principles Theoretical & Mathematical Derivations
- Algorithmic Design, Systems Architecture & Proofs
- Problem Sets, Implementations & Benchmark Labs
- Direct Theoretical Support for Downstream Machine Learning, Deep Learning & Cloud Systems
