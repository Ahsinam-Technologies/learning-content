# ML 304 — Bayesian Machine Learning

**Academic Classification:** Prerequisite for Bayesian HPO in SageMaker AMT  
**Phase in Master Curriculum:** Φ 07  
**Academic Prerequisites:** MATH 401, ML 102

## Course Overview
Bayesian linear/logistic regression, conjugate priors, Gaussian Processes, Bayesian Optimization, Markov Chain Monte Carlo (Metropolis-Hastings, Gibbs sampling), and Variational Inference.

---

## Key Curriculum Pillars
- First-Principles Theoretical & Mathematical Derivations
- Algorithmic Design, Systems Architecture & Proofs
- Problem Sets, Implementations & Benchmark Labs
- Direct Theoretical Support for Downstream Machine Learning, Deep Learning & Cloud Systems
