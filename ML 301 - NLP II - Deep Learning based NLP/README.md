# ML 301 — NLP II: Deep Learning based NLP

**Academic Classification:** Bridge from Classical NLP to Transformers  
**Phase in Master Curriculum:** Φ 07  
**Academic Prerequisites:** ML 205, ML 202  

---

## Course Overview
Word embeddings (Word2Vec, FastText, GloVe), Recurrent NLP models (BiLSTM-CRF), sequence-to-sequence models with attention, and subword tokenization algorithms.

---

## Key Curriculum Pillars
- First-Principles Theoretical & Mathematical Derivations
- Algorithmic Design, Systems Architecture & Proofs
- Problem Sets, Implementations & Benchmark Labs
- Direct Theoretical Support for Downstream Machine Learning, Deep Learning & Cloud Systems
