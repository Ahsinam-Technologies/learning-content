\subsection*{Diagnostic Checks and Decision Rules}

\begin{itemize}
  \item \textbf{Prior Predictive Check}: Compute $p(y_{\text{rep}}) = \int p(y_{\text{rep}} \mid \theta) p(\theta) d\theta$ to test if prior accommodates realistic data.
  \item \textbf{Posterior Predictive Check}: Simulate $y^* \sim p(y^* \mid y) = \int p(y^* \mid \theta) p(\theta \mid y) d\theta$ to inspect systematic model deviations.
  \item \textbf{Credible Interval vs.\ Confidence Interval}: A 95\% credible interval contains parameter $\theta$ with 0.95 epistemic probability conditional on observed data $y$.
\end{itemize}

\begin{shortcutbox}[Numerical Stability Rule]
Always store log-posteriors up to an additive constant: $\log \tilde{p}(\theta \mid y) = \ell(\theta) + \log p(\theta)$. Subtract $\max_{\theta} \log \tilde{p}$ before exponentiating.
\end{shortcutbox}
