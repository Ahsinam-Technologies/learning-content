# Shared fonts

These TTF files are downloaded from Google Fonts and used by the shared
XeLaTeX/LuaLaTeX theme:

- Outfit Regular and SemiBold for display headings.
- Inter Regular and SemiBold for body text.

Both typefaces are distributed under the SIL Open Font License. The build uses
the bundled files first and falls back to installed fonts when this folder is
not present in another checkout.
